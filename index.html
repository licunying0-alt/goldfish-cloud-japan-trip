交通与避坑

12/16 深圳南山 → 香港机场

06:30–07:00建议从南山出发，争取09:30抵达香港机场T1。收藏路线：深圳湾口岸 → B3X → 红桥 → A36 → 香港机场。具体车次、车费和衔接需出发前确认。

乐桃12:45起飞：参考值机开放10:15，截止11:55；尽量提前抵达，不要卡截止时间。

蛇口海天中转不可默认适用于乐桃香港出发航班，不能照搬其他航司攻略。

关西T2 → 酒店

到达T2国际区 → 等朋友会合 → 免费接驳巴士到Aeroplaza → 关西机场站乘南海电铁到新今宫 → 步行酒店。晚到后以入住、晚餐为主。

京都两日往返

酒店附近惠美须町 → 堺筋线到北滨 → 京阪电车往京都；清水寺日优先京阪清水五条或祇园四条，河原町日可用祇园四条。请用当日导航核对运营公司和站台。

日本生活小贴士

购物退税与行李

2026年11月起日本实施离境退税流程：购物时按规定付款，离境时按要求接受海关确认后办理退税。打算退税的商品请妥善保留并预留机场时间。乐桃行李额度按所购套餐核对。
